# European Travel Quiz

A beautiful, interactive web application that helps users discover their perfect European travel destination through a fun quiz with stunning visuals.

## Features

- **4 Engaging Questions**: Simple yes/no style questions about travel preferences
- **Visual Appeal**: Each question features relevant SVG illustrations
- **Modern UI**: Glassmorphism design with smooth animations and dark theme
- **Responsive**: Works perfectly on desktop and mobile devices
- **Interactive**: Click on category tiles to start, navigate with back/continue buttons
- **Result Page**: Shows Italy as the match with airline suggestions

## Technologies Used

- HTML5
- CSS3 (with animations, glassmorphism, and responsive design)
- JavaScript (ES6+)
- Google Fonts (Inter)
- SVG Illustrations

## How to Run

1. Clone the repository
2. Open `index.html` in a web browser, or
3. Use a local server: `python3 -m http.server 8000`

## Quiz Flow

1. **Start Page**: Choose a category tile to begin
2. **Quiz**: Answer 4 questions with visual cues
3. **Result**: See Italy recommended with travel tips

## Images

All illustrations are SVG files stored in the `images/` folder:
- food.svg, flags.svg, people.svg, clean-street.svg (quiz questions)
- colosseum.svg (result page)

The design features a dark gradient background with glassmorphism effects for a modern look.
